# ME 8284 Capstan Project

Fall 2026 ME 8284 group project, Team **Capstan** (University of Minnesota).

## Objective

Add a capstan and direct drive to a Haptic Telegraph and run a simple haptic program.

The capstan drive replaces the telegraph's geared actuation, similar to the Stanford Hapkit, to give smoother, more natural-feeling force feedback.
